# Director releases

Installers and auto-update files for **Director**, a [Core & Spoon](https://coreandspoon.com/projects/director) product.

Download the latest version from [Releases](https://github.com/bmp02050/director-releases/releases/latest).

Windows may show "Windows protected your PC" the first time. Click **More info → Run anyway**: the installer isn't code-signed yet.
